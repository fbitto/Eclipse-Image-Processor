# Control levels and layout

The Controls selector near the status area offers Basic (the default), Standard and Expert.

| Level | Filters and controls |
| --- | --- |
| Basic | NRGF, NAFE, FNRGF, MGN, AEL edge-aware WOW, Tangential, ACHF ISO 04 and ACHF Angular; filter opacity controls |
| Standard | All filters, with the former non-advanced controls |
| Expert | All filters and advanced parameters |

The first direct image load in Basic applies the [reviewed six-layer starter](layer-composition.md#basic-first-load-starter). Switching levels does not reapply it; existing recipes retain their controls. FNRGF and Tangential are available in Basic.

Entering Basic selects AEL NRGF statistics and edge-aware WOW, preserving eligible filters' on/off states. Hidden filters are disabled, and their numeric parameters are retained. Returning to Standard or Expert leaves those filters off. ACHF variants have separate cards in every level where they are available.

Preparation contains Input type, geometry and background/sky sampling. Input type offers only Linear and Non-linear (stretched), with Linear as the default. It is a user declaration; there is no automatic detection. Appearance contains Exposure, Calibrate color, Warmth and prominence controls. Warmth uses a plain label. Export has its own group; Full-resolution preview sits beside canvas zoom.

Version 4 recipes remain supported. The snapshot saves `ui_mode` as a stable string. Older snapshots map their Advanced flag to Standard or Expert, and their old unspecified input choice to Linear. Old explicit linear/non-linear selections are translated. ACHF include flags remain authoritative; restoring expansion state cannot re-enable an omitted variant. Basic restrictions apply after restoration and on new source loads.

Validation: all 455 unittest cases passed, including level switching, activation preservation, AEL choices, source loading and legacy recipe restoration. A separate native Windows review window was inspected in Basic, Standard and Expert, including Appearance ordering. This change has not received macOS visual validation.

Filter Statistics & Normalization groups AEL support separation, lunar/bright statistical exclusions, guard/percentile/annulus controls and Filter normalization directly after Background Gradient. The group is hidden in Basic and visible in Standard/Expert; changing levels preserves its values.
